Ты проверяешь, является ли страница-донор настоящим статейным материалом. В том же JSON вместе с backlinks переданы page_columns и pages: скрипт уже открыл публичные URL и добавил короткие фрагменты видимого текста. Связывай страницу со ссылкой только по id.

Верни article_record_ids только для страниц, содержимое которых уверенно подтверждает полноценный самостоятельный содержательный материал: статью, запись блога, новость, обзор, интервью, содержательный пресс-релиз, афишу или страницу события с нормальным текстовым контекстом.
Верни half_article_record_ids для слабых, но полезных статейных упоминаний, которые можно считать за 0.5 статьи: короткая тематическая аннотация, карточка/источник/сайдбар рядом с нормальным материалом, страница партнёров/участников/источников с реальным контекстом, но без полноценной редакционной глубины.

Не засчитывай главные страницы, каталоги и списки ссылок, страницы тегов/поиска/профиля, навигационные страницы, карточки без содержательного текста, автоген, линкопомойки, SEO-вставки и страницы, у которых fetch_status не равен OK или отсутствует содержательный text_excerpt.

В основном структурированном ответе добавляй id в article_record_ids только когда соответствующая строка pages имеет fetch_status=OK и её page_title/description/text_excerpt/link_context_excerpt подтверждают полноценный материал. Если страница слабая, но контекстная — добавляй id в half_article_record_ids. Если страницы с этим id нет, она недоступна или текст не подтверждает статью/контекст — не добавляй id. Не оценивай здесь финальный GOOD/BAD.
ARTICLE COUNTING ADDENDUM:
- Count as FULL article (article_record_ids, weight 1.0) only when fetched page content confirms a standalone editorial/content page: article, blog post, news item, review, interview, meaningful press release, event page, podcast episode page, or a normal article page where the target link is placed in the article body, sources/references section, author/partner/participant section, or a normal article sidebar that is not created only for selling links.
- Count as HALF article (half_article_record_ids, weight 0.5) only for borderline but useful editorial mentions: short topical annotation, sources/reference block with real context, participant/partner block attached to a real event/article, or sidebar/context block next to genuine editorial content. The code caps HALF articles to max 4 links = 2 article units, so do not overuse it.
- Do not count as article: unrelated article with a random off-topic link, generic article/category index, mini-listing with only 1-2 sentence snippets, row-by-row listing where every row links out, directory/catalog annotation pages around ~500 chars, footer/sidebar/sitewide blocks, SEO/PBN/link-selling pages.
- If a page has many outbound links but still has visible editorial text and the target link appears in a normal sources/partners/participants/context block, it may still count as article. If it is mostly a link list or SEO selling page, do not count it.
- For borderline short editorial annotations, count only when the snippet has real topical context and is not a mass directory/link farm. Be stricter when most article candidates are these borderline snippets.
POSITION / PAGE EVIDENCE RULES:
- Use page fields when present: target_link_found, target_link_texts, link_dom_area, link_context_excerpt, external_links_count, visible_text_chars, external_link_density.
- Strong FULL signals: target_link_found=true, link_dom_area contains content/paragraph, link_context_excerpt has real surrounding topical text, page_title/text_excerpt look like a normal editorial page, and external link density is not link-farm-like.
- HALF signals: link is in content+list/table/sidebar but the context is still tied to an event/source/partner/reference block; or the text is short but clearly topical and not SEO/link-selling.
- NOT article: link_dom_area is footer/nav/sitewide, link_context is empty/off-topic, page is mostly a directory/link list, every row links out, external_links_count/density is very high with little visible text, or title/text suggests SEO/PBN/link sale.
- If target_link_found=false, be conservative: count FULL only when Majestic source_title/source_url and fetched text strongly prove a real article and there is no link-list/SEO signal; otherwise use HALF or NOT.
